Entry for the [One-Line Office Jokes](https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc) bounty on make.fun.

## Entry

> I replied-all 'Thanks!' to the whole company, and now the whole company is replying-all 'Thanks!' to me.

## How it works

`main.py` writes the single one-line joke above to `/output/entry.txt`.
The program is fully deterministic: the same joke on every run, no randomness,
no network access, no input files needed.

## Run

```sh
python3 main.py
```

The output is written to the directory in `MAKEFUN_OUTPUT_DIR` (default `/output`).
